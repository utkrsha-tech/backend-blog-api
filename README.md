# Backend Blog API (Module 02 - Codomax Internship)

Node.js and Express.js REST API backend for my full-stack blogging application.

## API Endpoints
- `POST /api/auth/register` — Create a new user account
- `POST /api/auth/login` — Sign in user & generate session token
- `GET /api/blogs` — Fetch all blog posts
- `POST /api/blogs` — Publish a new blog post (Protected)

## Running Locally
```bash
npm install
npm start
